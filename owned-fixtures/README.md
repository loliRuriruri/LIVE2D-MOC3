# Owned fixtures (private, never committed)

Place real Live2D models that you own or are authorized to analyze here
(e.g. `model.moc3`, `model3.json`, `textures/`). Everything except this
README and `.gitignore` is ignored by git.

Run them with:

    Live2DRecovery.exe recover model3.json --output recovered.cmo3

Reports may record file hashes and counts only; do not paste private asset
data into tracked documents.
