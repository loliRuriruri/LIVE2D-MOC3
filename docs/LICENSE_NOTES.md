# License Notes and Reference Policy

**No third-party source code was copied into this repository.** The parser is
an original Rust implementation written for this project. Public references
were used only as *format references* (field layouts, documented behaviour,
validation rules) and are listed below with their licenses and the exact role
they played.

## Reference usage policy

Allowed (used here):

- reading public format specifications and clean-room implementations to
  learn the file layout,
- cross-checking field semantics between independent sources,
- citing sources in `docs/FORMAT_NOTES.md` and `docs/RESEARCH_LOG.md`.

Not allowed (and not done):

- copying code, comments, or identifiers verbatim from any reference,
- using references whose license forbids derived use as a source of code,
- bundling third-party model data, Cubism Core binaries, or Live2D assets.

## Data policy

- `fixtures/synthetic/**` contains only files generated by
  `tools/fixture-gen` in this repository (pure synthetic values, `Synthetic`
  identifiers).
- `fixtures/owned/**` is empty by design; only user-owned or explicitly
  authorized files may be added there (see `fixtures/owned/README.md`).
- The toolkit does not download anything, does not decrypt or bypass
  protection, and only reads files the user points it at (master spec
  section 2, non-goals).
