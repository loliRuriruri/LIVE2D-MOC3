# Fixtures

Fixture policy (master spec sections 2 and 20):

1. **synthetic/** - generated by `tools/fixture-gen` (this repository). Pure
   synthetic data, no third-party content. Checked in so tests are hermetic.
   Regenerate with:

   ```text
   cargo run -p fixture-gen -- fixtures/synthetic
   ```

2. **owned/** - for models the user owns or is explicitly authorized to
   analyze. Ships empty on purpose. Do not add third-party model data here
   without documentation of ownership/authorization.

3. **expected/** - golden inspection reports (`<fixture>.report.json`),
   produced by `recovery inspect <fixture> --json`. Regenerate with:

   ```text
   $env:UPDATE_GOLDEN="1"; cargo test -p moc3-ingest --test parse_fixtures
   ```

The checked-in synthetic fixtures are verified against the generator by
tests (`checked_in_fixtures_match_generator`), so they cannot silently drift.
