# Live2D Project Recovery Tool

Reconstructs editable project structure from Live2D Cubism **runtime files**
that the user owns or is authorized to analyze:

```text
.moc3 (+ model3.json + textures, later)
        |
   MOC3 Ingest          (read-only parser)          <- implemented
        |
   Live2D IR            (normalized representation) <- AGENT.2
        |
   Recovery Graph       (hierarchy reconstruction)  <- AGENT.3/4
        |
   CMO3 Writer          (editor project output)     <- AGENT.5
        |
   Structural Validation (comparison engine)        <- AGENT.7
```

**Current status: AGENT.0 (research/bootstrap) and AGENT.1 (read-only MOC3
inspector) complete and passing all acceptance criteria.** No CMO3 writer, no
PSD recovery, no GUI - those are gated behind later phases (master spec
v0.1).

## Quickstart

```text
cargo build --release

recovery inspect path\to\model.moc3
recovery inspect path\to\model.moc3 --json > report.json

cargo test
cargo clippy --workspace --all-targets
```

The inspector reports: MOC3 version, canvas, counts, parameter ids,
parts, drawables (art meshes), deformers, texture references, masking
relationships, hierarchy candidates with confidence, runtime scratch
sections, anomalies, and what is intentionally not extracted yet.

## Legal / scope

- Only user-provided local files are read; nothing is downloaded, decrypted,
  or extracted from games/services. No DRM/license bypass. See master spec
  section 2 and `docs/LICENSE_NOTES.md`.
- All checked-in model data is synthetic (`fixtures/`), generated by this
  repository. Third-party Live2D sample data is **not** included.
- References were used as format/behaviour references only; no third-party
  code was copied. Details in `docs/LICENSE_NOTES.md`.

## Repository layout

```text
crates/moc3-ingest/       read-only MOC3 parser + inspection report
crates/recovery-core/     file IO + inspection orchestration
apps/recovery-cli/        `recovery` binary
crates/live2d-ir/         (reserved: AGENT.2)
crates/hierarchy-recovery/(reserved: AGENT.3)
crates/cmo3-writer/       (reserved: AGENT.5)
crates/project-validator/ (reserved: AGENT.7)
crates/texture-tools/     (reserved: AGENT.8)
tools/fixture-gen/        synthetic fixture writer (tests only)
fixtures/                 synthetic / owned / expected data policy
tests/workspace-smoke/    cross-crate integration tests
docs/                     architecture, format research, test plan, ...
```
